# Easy Scripts

These scripts are for someone who just downloaded the repo and wants immediate results.

Run from repo root:

```bash
bash scripts/easy/02_analyze_and_plot.sh input.wav out
bash scripts/easy/03_extract_single_moment.sh input.wav out/moments
bash scripts/easy/05_generate_signal_graphs.sh docs/examples/signal_window_guide
```

Notes:
- `02_*` and `03_*` use `esl`.
- `05_generate_signal_graphs.sh` generates signal/window/STFT visual assets for docs.
