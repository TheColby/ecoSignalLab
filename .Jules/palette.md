## 2025-05-15 - Improving Documentation Navigation and Accessibility
**Learning:** Adding `aria-current="page"` and a visual `.active` class to sidebar links significantly improves the "you are here" experience for all users. Using `Path.resolve()` is crucial for reliably matching current pages across different directory structures. Implementing a skip-to-content link is a low-effort, high-impact accessibility win for keyboard users.
**Action:** Always ensure documentation generators include active-state indicators and keyboard-friendly skip links.
