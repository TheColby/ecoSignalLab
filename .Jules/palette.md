## 2025-05-14 - Documentation "Copy to Clipboard" Utility
**Learning:** Adding a "Copy" button to code blocks in static documentation is a high-value micro-UX improvement that reduces friction for developers. It's important to use accessible labels (ARIA) and provide visual feedback (e.g., "Copied!") to confirm the action.
