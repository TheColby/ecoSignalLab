# ecoSignalLab v0.3.0

ecoSignalLab (`esl`) is a command-line toolkit for environmental, architectural,
and multichannel acoustic analysis. This release expands archive workflows,
human review, spatial diagnostics, and reproducible feature exports.

## Highlights

- Offline moment-review packets with audio previews, spectrograms, labels, and
  resumable CSV annotations: `esl moments review`.
- Explicit baseline comparisons and block-bootstrap uncertainty estimates:
  `esl monitor compare` and `esl uncertainty`.
- Bounded spatial timelines and streaming recorder QA: `esl spatial-timeline`
  and `esl qa`.
- Provenance-addressed spectral and local TorchScript embeddings with persistent
  SQLite vector search: `esl embeddings` and `esl index`.
- Measurement protocols and audited multichannel interval masking, including
  automatic RF64 selection for large redacted outputs: `esl protocol` and
  `esl privacy redact`.
- Leased archive jobs with same-host SQLite and multi-host PostgreSQL backends,
  fenced result commits, and optional HTTP/S3 staging: `esl archive-jobs`.
- Archive manifests, resumable processing, calibration verification, spatial
  metadata, and appendable FrameTable workflows.
- Expanded linked documentation with rendered equations, Mermaid diagrams,
  terminal-green code blocks, user guide, and 498-page textbook.

## Install and Check

Version 0.3.0 is available on [PyPI](https://pypi.org/project/ecosignallab/0.3.0/).
Install in an activated virtual environment:

```sh
python -m pip install ecosignallab==0.3.0
esl --version
esl doctor
esl quickstart
```

Optional extras include `archive`, `docs`, `features`, `io`, `ml`, and `plot`.
For example, add PostgreSQL/S3 clients with:

```sh
python -m pip install "ecosignallab[archive]==0.3.0"
```

Python 3.10 or newer is required. Install FFmpeg and ffprobe for compressed audio.
The Release workflow publishes GitHub assets. The dedicated PyPI workflow
publishes the verified wheel and source distribution using Trusted Publishing.

## Compatibility and Scope

The package version is `0.3.0`; the analysis JSON schema remains `0.2.0`.
New workflow artifacts have separate versioned contracts. Existing analysis and
moments commands remain available. See the
[workflow guide](https://github.com/TheColby/ecoSignalLab/blob/v0.3.0/docs/ADVANCED_WORKFLOWS.md)
for exact inputs, units, assumptions, and resource bounds.

Spatial outputs are first-order broadband proxies. The default embedding is
spectral; learned-model behavior depends on a user-supplied local model.
Privacy masking uses supplied or hook-generated intervals and requires human
review. Archive workers currently execute per-channel RMS/peak summaries.
PostgreSQL coordinates multiple machines; SQLite queues require a local file on
one host. These contracts are documented alongside the algorithms.
